# GXEON x402scan Discovery

This origin exposes OpenAPI-first discovery at `/openapi.json` and the compatibility manifest at `/.well-known/x402`.

## Paid resources
- `POST /x402/csv-audit` — 0.01 USD per request, x402 on Base / USDC.
- `POST /x402/json-validate` — 0.01 USD per request, x402 on Base / USDC.

## Discovery contract
- Each operation declares `x-payment-info`, a 402 response, and a `Payment-Signature` security scheme.
- Runtime HTTP 402 challenge and its non-empty `accepts` array are authoritative for payTo, asset, network and atomic amount.
- The challenge includes Bazaar input/output metadata generated by `describeX402Service`.
- The static OpenAPI price metadata must remain aligned with `src/agent-economy/x402/pricing.ts`.
- The Zyla origin adapter is separate and is not advertised as a paid x402 resource.

## Validation before registration
1. Deploy the discovery branch to a protected Preview.
2. Fetch `/openapi.json` and `/.well-known/x402`; validate JSON and exact absolute resource URLs.
3. Probe each resource with unauthenticated POST and confirm HTTP 402, parseable x402 v2 challenge, non-empty `accepts`, Base network `eip155:8453`, USDC asset and amount in atomic units (`10000` for 0.01 USDC).
4. Confirm Bazaar extension input and output schemas match the actual POST contract.
5. Run `npx -y @agentcash/discovery <preview-host> -v` against the preview host.
6. Register the production origin in x402scan only after the discovery deployment is reviewed and promoted.

Do not expose secrets in OpenAPI or discovery metadata. Do not treat static price metadata as a substitute for the live 402 challenge.
