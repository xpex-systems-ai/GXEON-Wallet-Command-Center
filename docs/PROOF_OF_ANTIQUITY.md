# PROOF OF ANTIQUITY (PoA) ARCHITECTURE

## Consensus Mechanism
Proof of Antiquity validates computing hardware age, instruction set latency, and continuous uptime without excessive energy consumption.

### Multiplier Rules
- Multiplier is initialized as `null` / `UNCONFIRMED`.
- Only verified, cryptographically signed hardware benchmarks elevate the multiplier above `1.0x`.
- Simulated or synthetic multiplier increments are strictly rejected by the UI and event bus.
