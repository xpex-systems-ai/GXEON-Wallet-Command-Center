# GXEON AgentFi OS — Productization Plan

## Market signal
A third-party GitHub account forked GXEON Wallet Command Center. The fork is currently **0 commits ahead** of XPeX and **211 commits behind** the current XPeX main branch. Its merge base is `88db666a...`. Therefore the evidence supports **external technical interest / preservation of an earlier snapshot**, not yet proof of adoption, integration, partnership, or commercial intent.

The same account also maintains/forks repositories named `Rustchain` and `BountyScout`. That is ecosystem proximity, not proof that the account represents RustChain maintainers.

## Product
**GXEON AgentFi OS — Contributor Economy Control Plane**

A deployable, white-label control plane for bounty and agent economies:
- contributor identity and agent capability registry;
- task/bounty discovery and qualification;
- bounded agent execution;
- evidence ledger and independent verification;
- payout lifecycle reconciliation;
- multi-asset watch-only treasury;
- policy/risk engine;
- human-gated settlement;
- MCP/API gateway for AI operators;
- mobile-first private operator cockpit.

## Editions
### Community
Self-hosted observability, task pipeline and evidence ledger.

### Operator Cloud
Managed deployment, private authentication, monitoring, updates and support.

### Ecosystem / White Label
Branded deployment for a bounty network or agent economy with custom adapters, governance, reporting and SLA.

### Enterprise
Dedicated tenant, SSO/RBAC, audit export, policy packs, private connectors and deployment options.

## Commercial model
Prefer **software licensing / managed SaaS / white-label deployment** over “franchise”. A franchise implies a different legal and operational structure that is unnecessary for a software control plane.

Commercial terms must be negotiated separately. No public fork is treated as acceptance of a sales offer.

## Mobile product
Ship first as an installable authenticated PWA. Native wrappers can follow after the security and workflow contract stabilizes.

## Security baseline
Owner/tenant authentication, server-side authorization, least privilege, isolated signing, no secrets in clients, independent verifier, append-only evidence intent, rate limiting, audit logs, dependency/secret scanning and fail-closed financial actions.
